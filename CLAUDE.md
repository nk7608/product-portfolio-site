# Working on this portfolio

Use the project skills before changing anything visible:
- `portfolio-ux-patterns` — layout, sections, copy, page budgets (measure script), mobile.
- `portfolio-visual-language` — fonts, themes, accents, states; no decorative effects (contrast script).
- `portfolio-onboarding-journeys` — intro, personas, section order.
- `portfolio-user-controls` — Settings, ⌘K, saved preferences.

Validate with `pnpm typecheck && pnpm lint && pnpm test && pnpm build`. Research: `docs/RESEARCH-2026-10.md`.
