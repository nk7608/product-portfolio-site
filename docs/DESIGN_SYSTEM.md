# Design system

The rules live in project skills so they stay next to the code and get used:

- `.claude/skills/portfolio-visual-language` — fonts, themes (Paper, Stone, Ink, Night), accents, states, anti-slop list, contrast script.
- `.claude/skills/portfolio-ux-patterns` — page shape, information budget, copy rules, measure script.
- `.claude/skills/portfolio-onboarding-journeys` — first-visit intro, personas and section order.
- `.claude/skills/portfolio-user-controls` — Settings, ⌘K, persistence.
